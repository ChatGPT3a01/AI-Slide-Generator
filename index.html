系統架構說明

🎯 這個專案是什麼?

這是一個本機端運行的 AI 簡報自動生成系統，透過 Python Flask 提供網頁界面，將需求傳送到 Google Apps Script 處理，再呼叫 AI API 生成專業簡報。

系統運作流程

步驟 1: 在本機啟動 Flask 伺服器 (localhost:5000)
步驟 2: 在網頁界面填寫簡報需求
步驟 3: 資料傳送到 Google Apps Script
步驟 4: GAS 呼叫 AI API 生成內容
步驟 5: 選擇使用 AI 生成或套用模板
步驟 6: 下載 HTML 簡報檔案
🖥️ Flask 本機端

Port: 5000

功能:

  • 提供網頁界面
  • 接收使用者輸入
  • 與 GAS 通訊
  • 儲存生成的簡報
☁️ Google Apps Script

部署: Web 應用程式

功能:

  • 接收 Flask 請求
  • 呼叫 AI API
  • 處理模板渲染
  • 記錄到 Google Sheets
🤖 AI 生成

支援: Gemini / OpenAI

兩種模式:

  • 完全 AI 生成: 創意自由
  • 模板生成: 專業美觀
  • 同時生成: 比較選擇

完整部署設定

📝 第一步：部署 Google Apps Script

1.1 建立 GAS 專案
  1. 前往 Google Apps Script
  2. 點擊「新專案」
  3. 命名為「AI簡報生成系統」
1.2 貼上程式碼
  1. 刪除預設的程式碼
  2. 開啟專案中的 GAS_code.js
  3. 複製完整內容並貼到 Apps Script 編輯器
  4. 點擊儲存 (💾)
1.3 部署為 Web 應用程式
  1. 點擊右上角「部署」→「新增部署作業」
  2. 選擇類型：「網頁應用程式」
  3. 設定執行身分：我
  4. 具有存取權的使用者：任何人
  5. 點擊「部署」
  6. 重要! 複製「網頁應用程式 URL」
⚠️ 授權提醒

首次部署時 Google 會要求授權，點擊「進階」→「前往 AI簡報生成系統(不安全)」→「允許」。這是正常流程！

🐍 第二步：設定本機 Flask

2.1 設定 GAS URL
  1. 開啟 app.py
  2. 找到第 14 行：GAS_URL = "你的GAS網址"
  3. 將其替換成你剛複製的 GAS URL
  4. 儲存檔案
2.2 安裝 Python 套件

在專案目錄執行：

pip install -r requirements.txt

或個別安裝：

pip install Flask==3.0.0 requests==2.31.0
2.3 啟動 Flask 伺服器
python app.py

看到這個訊息表示成功：

* Running on http://127.0.0.1:5000 * Debug mode: on
✅ 完成設定

在瀏覽器開啟：http://127.0.0.1:5000

應該會看到「AI 簡報自動生成系統」界面

🔑 第三步：取得 AI API 金鑰

✅ 免費額度充足

  1. 前往 Google AI Studio
  2. 點擊「Get API Key」
  3. 建立或選擇專案
  4. 點擊「Create API Key」
  5. 複製金鑰

  5. 需要先充值帳戶

詳細使用教學

1️⃣ API 設定區塊

  • 選擇 AI 服務：Gemini 或 OpenAI
  • 貼上 API Key：在上一步取得的金鑰
  • 選擇模型：Gemini 3.5 Flash (推薦)、GPT-5.6 Terra
  • 生成方式：
    • 完全由 AI 生成 - 創意度高
    • 使用模板 - 美觀穩定 ⭐
    • 兩種都生成 - 可以比較選擇

2️⃣ 簡報基本資訊

  • 主題：簡報的核心主題（例：AI 在教育的應用）
  • 對象：聽眾是誰（例：大學生、企業主管）
  • 關鍵字：用逗號分隔（例：AI, 教育, 創新）
  • 目的：要達成什麼（例：介紹產品、教學）

3️⃣ 簡報設定

  • 頁數：5-20 頁（建議 8-12 頁）
  • 類型：商務報告、產品介紹、教學培訓、學術研究、創意提案
  • 風格：專業、創意、學術、輕鬆
  • 色彩主題：藍色系、暖色系、企業色、活潑色
💡 使用技巧
  • 首次使用：建議選「使用模板」，品質穩定
  • 頁數建議：8-12 頁最適合
  • 關鍵字：3-5 個最佳
  • 生成時間：正常 10-30 秒

常見問題解答

Q1: GAS 部署後無法存取？

A: 確認部署時選擇「任何人」都可存取，並重新部署一次。檢查是否完成授權流程。

Q2: API Key 無效？

A: 確認已在 AI Studio 啟用 API，並檢查金鑰是否完整複製（沒有多餘空格）。

Q3: 簡報生成失敗？

A: 按 F12 開啟瀏覽器 Console 查看錯誤訊息。確認 app.py 中的 GAS_URL 設定正確。

Q4: 生成速度太慢？

A: 減少簡報頁數（建議 8-12 頁），使用 Gemini 3.5 Flash，選擇「使用模板」模式。

Q5: 如何停止 Flask 伺服器？

A: 在終端機按 Ctrl + C

如何修改模板？

編輯 GAS_code.js 中的模板函數：

  • generateWithTemplate() - 現代雙欄式
  • generateTutorialTemplate() - 教學步驟式
  • generateClassicTemplate() - 經典全屏式

⚠️ 修改後記得在 Apps Script 重新部署！

⚠️ 開發注意事項
  • 修改 Flask 路由後需重啟伺服器
  • GAS 部署為新版本才會套用更新
  • 測試時建議使用較少頁數避免超時
  • API Key 不要提交到版本控制系統
