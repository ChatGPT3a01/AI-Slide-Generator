系統簡介

這是什麼系統？

這是一套完整的 AI 簡報自動生成系統，結合了 Flask Web 框架、Google Apps Script 和 AI API（Gemini 或 OpenAI）， 能夠根據使用者輸入的主題和需求，自動生成精美的互動式簡報。

主要功能
  • 支援 Gemini 和 OpenAI 兩種 AI 服務
  • 三種模板風格：現代雙欄式、教學步驟式、經典全屏式
  • 完全自訂簡報風格、色彩主題和頁數
  • 自動生成互動式 HTML 簡報
  • Google Sheets 自動記錄生成歷史
系統架構
  • 前端：HTML + CSS + JavaScript
  • 後端：Python Flask
  • 雲端服務：Google Apps Script
  • AI 引擎：Gemini / OpenAI GPT
  • 資料庫：Google Sheets
適合對象

教師、學生、企業人士、簡報設計師，或任何需要快速製作專業簡報的人。 無需設計經驗，AI 會自動處理排版、配色和內容組織。

常見問題 FAQ

API Key 要錢嗎？

Google Gemini 提供免費額度（每分鐘 15 次請求），對於個人使用已經相當充足。 OpenAI 則需要付費，但新用戶可能有免費額度。

生成的簡報可以編輯嗎？

可以！下載的 HTML 檔案可以用任何文字編輯器或程式碼編輯器打開並修改內容。

為什麼生成失敗？

可能的原因：

  • • API Key 無效或已過期
  • • API 額度用完
  • • 網路連線問題
  • • GAS 網址設定錯誤
簡報可以匯出成 PowerPoint 嗎？

目前系統產生的是 HTML 格式的互動式簡報。您可以使用瀏覽器的「列印」功能將簡報儲存為 PDF。 若需要 PowerPoint 格式，建議使用轉換工具或手動複製內容。

可以商業使用嗎？

本系統程式碼為開源專案，您可以自由使用、修改和商業化。但請注意，使用 AI API 時需遵守各平台的服務條款。

簡報儲存在哪裡？

生成的簡報會自動儲存在 static/presentations/ 資料夾中。 同時，生成記錄會自動記錄到 Google Sheets（如果您在 GAS 中有設定）。
