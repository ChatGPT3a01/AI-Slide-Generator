STEP 1下載專案 & 安裝套件

打開終端機（VS Code：Terminal → New Terminal），逐行照打：

# 下載專案 git clone https://github.com/ChatGPT3a01/AI-Slide-Generator.git cd AI-Slide-Generator # 安裝相依套件（Flask、requests） pip install -r requirements.txt Successfully installed Flask-3.0.0 requests-2.31.0 ... ← 看到就成功
💡 沒有 git？也可以在 GitHub 頁面按「Code → Download ZIP」下載後解壓縮，再 cd 進資料夾。

STEP 2設定 Google Apps Script（雲端後端）

  1. 前往 script.google.com，建立新專案。
  2. 把專案裡的 GAS_code.js 內容整段貼進去。
  3. 右上「部署 → 新增部署作業 → 網頁應用程式」。
  4. 執行身分選「我」、存取權選「任何人」→ 部署。
  5. 複製產生的網頁應用程式網址（等一下要用）。
⚠️ 存取權一定要選「任何人」，否則 Flask 呼叫 GAS 會被擋（403）。

STEP 3把 GAS 網址填進 Flask

用 VS Code 打開 app.py，找到這一行，把剛剛複製的網址貼上：

# app.py GAS_URL = "貼上你的 GAS 網頁應用程式網址" # 例：https://script.google.com/macros/s/AKfyc.../exec
✅ 存檔（Ctrl/Cmd + S）。這一步等於把「本地前端」和「雲端後端」接起來了。

STEP 4啟動系統

回到終端機，啟動 Flask：

python app.py * Running on http://localhost:5000 ← 看到這行就啟動成功

打開瀏覽器，前往 http://localhost:5000，就會看到簡報生成表單。

⚠️ 找不到 python？Windows 試 py app.py；Mac 試 python3 app.py。

STEP 5生成你的第一份簡報

  1. 填寫表單：主題、對象、關鍵字、頁數。
  2. 選 AI 服務：Gemini（推薦，免費）或 OpenAI。
  3. 選生成模式：模板填充（穩定推薦）／完全 AI／兩者比較。
  4. 按「生成」，等 30–60 秒。
  5. 預覽 / 下載 HTML 簡報（可用鍵盤 ← → 播放）。
🎉 恭喜！你已經有一套「填表單就生成簡報」的 AI 系統了。
